
# 🛡️ CIA Triad: Protecting Organizations

The **CIA Triad** is a foundational model in cybersecurity that helps organizations evaluate and manage risk. It stands for:

| Element         | Description                                                                 |
|------------------|-----------------------------------------------------------------------------|
| **Confidentiality** | Only **authorized users** should have access to specific data or systems. This is often enforced using the **principle of least privilege**, where users only get access to what they need. |
| **Integrity**       | Data should remain **accurate, authentic, and tamper-proof**. Common tools to enforce integrity include **encryption** and **cryptographic protocols**. |
| **Availability**    | Data must be **accessible when needed** by the right people. This involves making sure systems are reliable and access is granted appropriately. |

## ✅ Why the CIA Triad Matters
Maintaining a balance between these three principles helps organizations:

- Protect sensitive information from leaks or unauthorized access (**Confidentiality**)
- Ensure trust in their data (**Integrity**)
- Maintain day-to-day operations without disruption (**Availability**)

Security analysts use the CIA Triad to guide decisions when designing systems, writing policies, or responding to incidents.
